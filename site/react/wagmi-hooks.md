Use this table to find the Reactive hook for each public Wagmi React hook. It covers all 70 root exports (including three deprecated aliases) from [the pinned Wagmi revision](https://github.com/wevm/wagmi/blob/391793e24bcf8eaa7565b266fb988934ac39903f/packages/react/src/exports/index.ts). ## Contract factories and Tempo

All four contract hook factories are available for binding an AE contract address and entry point or event. [Contract hook factories](./contract-hook-factories)

For token integrations, start with [AEX-9 metadata](./api/hooks/useTokenMetadata), [balance](./api/hooks/useTokenBalance), [transfers](./api/hooks/useTransferToken), [allowances](./api/hooks/useTokenAllowance), [mint](./api/hooks/useMintToken), [burn](./api/hooks/useBurnToken) and [event watching](./api/hooks/useWatchContractEvent). Optional entry points depend on the deployed token.

| Tempo use case | What an æternity application can use |
|---|---|
| Account nonce and transfers | [Account nonce](./api/hooks/useTransactionCount), [native AE spend](./api/hooks/useSpend), or [AEX-9 transfer](./api/hooks/useTransferToken). Tempo's keyed nonces require a different protocol. |
| AMMs, order books, policies and rewards | The application supplies the network, contract address, entrypoint and arguments from its ACI. Bind a [read, simulation, write or event hook](./contract-hook-factories). |
| Fee-token selection, zones and verifiable withdrawals | These depend on Tempo protocol rules. Æternity nodes expose different fee and authorization mechanisms. |
| Testnet faucet | Funding depends on an external service for the selected network. |

The [full extension inventory](https://github.com/growae/reactive/blob/develop/ROADMAP.md#tempo-extension-inventory) records the decision for each of the 130 Tempo hooks.
