# Reactive roadmap

The immediate release objective is to run protocol operations through Rust in JavaScript, Dart, and Python and remove the JS SDK from the runtime dependency graph. The maintainer approved a smaller breaking release. Return withdrawn APIs only after their dependencies can be implemented on this stack. The hook backlog below compares user-visible behavior rather than requiring Ethereum names on æternity. Reactive ships chain operations and shared interfaces. Application deployments and their ACIs belong to the consumer.

## Rust binding release gates

| Gate | Implemented in the working tree | Remaining work and exit check |
|---|---|---|
| Wire operations | Rust powers JS transaction building, pricing, local signing, and the public spend action. All three bindings exercise the common 41-vector corpus. | Keep under test as the wire surface grows. |
| Node and wallet | Fetch-based node v3 transport, Rust memory signer, custom connectors, mock and MetaMask Snap. SDK-free public manifests. | Rust now powers AE typed data and contract calls; additional wallet integrations still depend on the individual wallet. The [migration guide](site/core/rust-protocol.md) lists withdrawals. |
| Sophia and mobile | JS builds FATE calldata, dry-runs Sophia calls, signs writes, and reads indexed logs. Python wheels and desktop Dart support the transaction core. | JS now exposes explicit FATE values, contract calls, and typed data. Full ACI inference and Flutter mobile bundling remain future work. |
| Independent coverage | 27/27 transaction schema entries and 176/200 fields in the differential report. | Add omitted-fee reference vectors, independent fixtures for 25 state-entry pairs and missing FATE variants. Resolve the recorded ChannelForceProgressTx exception. [Matrix](crates/ae-parity/MATRIX.md) · [Node record](crates/ae-parity/TESTNET.md) |
| Consumer gate | Pack the real npm artifacts, reject a transitive SDK, and load the bundled WASM from an installed package. | Run this gate and the desktop-native suites for each release. The fixture generator and independent tests use the old SDK as a development reference. |

## Hook delivery status

The React entry point now covers 65 of the 70 upstream root names through public AE operations and two more through opt-in wallet connectors. The three Ethereum-specific rows identify the protocol feature that has no AE equivalent. [Public hook crosswalk](site/react/wagmi-hooks.md) · [Sophia arguments and results](site/core/sophia-contracts.md) · [Contract hook factories](site/react/contract-hook-factories.md)

For each Tempo hook, first check whether æternity or a public standard defines the operation. AEX-9 provides reusable token operations. When the semantics belong to an application, bind the application's own ACI and network via the contract hooks. Add a public SDK hook when a shared protocol or standard supplies a contract-independent interface. Keep the upstream inventory and hook reference pages in sync.

## Contract hook factories
