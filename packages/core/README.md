# @growae/reactive

Fetch-based æternity actions and the lazy Rust protocol module at `@growae/reactive/protocol`. Use the core for node reads, transaction building, signing, and spends.

See the [supported APIs and migration](https://github.com/growae/reactive/blob/develop/site/core/rust-protocol.md) for the 0.2 release and the features available on the 0.1 line.
