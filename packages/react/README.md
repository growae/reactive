# @growae/reactive-react

React hooks for æternity wallets, transactions, Sophia contracts, indexed events, AEX-9 tokens and AENS. Use `ReactiveProvider` and TanStack Query. The `@growae/reactive-react/codegen` entry point creates reusable hooks for an application's own network and contract interface.

See the [supported APIs and migration](https://github.com/growae/reactive/blob/develop/site/core/rust-protocol.md) for the 0.2 release and the features available on the 0.1 line.
